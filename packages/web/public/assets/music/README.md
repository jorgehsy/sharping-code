# Music

`old-tower-inn.mp3`: "Medieval: The Old Tower Inn" (loop version) by RandomMind, CC0 1.0
(http://creativecommons.org/publicdomain/zero/1.0/). Source: https://opengameart.org/content/medieval-the-old-tower-inn

Made from `Loop_The_Old_Tower_Inn.wav`: its last 0.5 s were crossfaded into the start (the original seam jumps and clicks),
then encoded to 128k mp3. `src/sound/music.ts` loops it with Web Audio and trims any encoder padding.
